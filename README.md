# JAY App — Endless Runner 🎮

A free, mobile-friendly endless runner game built with plain HTML, CSS, and JavaScript. No frameworks, build steps, accounts, or paid services required to play.

## Play

- Tap **LET'S RUN** to begin.
- Tap the game area or **JUMP**, or press **Space**, **↑**, or **W** to jump.
- Avoid the glowing blocks, build your score, and beat your personal best.
- Use **RESTART** to try again.

The best score is saved in your browser on that device. The game is designed for phones and desktop browsers.

## Host free with GitHub Pages

The `main` branch root contains `index.html`. In the repository, open **Settings → Pages** and select **Deploy from a branch**, branch **main**, folder **/(root)**, then save. Once GitHub finishes building, the site is available at `https://sambasbockarie874-hub.github.io/jay-app/`.

## Technology

Vanilla HTML, CSS, Canvas, and JavaScript. No external dependencies or tracking scripts.
